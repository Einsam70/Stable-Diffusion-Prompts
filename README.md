# 1. Función

Aplicación para administrar estilos para generación de imágenes con IA (Stable diffusion). Permite editar estilos, añadir nuevos, previsualización, copiar prompts para utilizar en Forge o Neo...

# 2. Como utilizar

![Imagen mostrando aplicación 1](/screenshots/imagen1.png)

### Estilos:

En la carpeta estilos del proyecto estan predefinidos dos archivos CSV (como el que encontrarás en la carpeta de Neo o Forge) con numerosos estilos ya definidos. Pueden ser incorporados directamente a tu software de generación de imágenes aunque recuerda que el archivo se debe llamar **styles.csv** para que sea reconocido.

En esta aplicación podrás seleccionar el archivo csv con los estilos que deseas explorar, no debe ser necesariamente uno de los aportados como ejemplo, puedes consultar cualquier otro que tengas. El problema lo encontrarás a la hora de previsualizar los ejemplos vinculados, ya que estos sí deben estar en la carpeta imagenes y sus nombres han de ser igual al del estilo:

Por ejemplo:

- Estilo: Anime
- Imágenes: anime1.jpg, anime2.jpg, anime3.jpg

### Imágenes

El único requisito es el formato, ha de ser jpg. Si además quieres que aparezcan cuando se visualiza el estilo, deberan tener un nombre idéntico al del estilo y estar en la carpeta imagenes.

![Imagen mostrando aplicación 1](/screenshots/imagen2.png)

### Otras funciones

Además podrás copiar directamente  los prompts (negativos y positivos) para utilizarlos en tu IA de imágenes, editar los estilos existentes o añadir nuevos.
